# number-guessing-game

## How to Run the Game

Open your terminal in the project directory and follow these commands to set up the environment and run the game:

```bash
# 1. Create a virtual environment
python -m venv .venv

# 2. Activate the virtual environment
# On macOS / Linux:
source .venv/bin/activate
# On Windows:
.venv\Scripts\activate

# 3. Run the game script
python3 guess.py
